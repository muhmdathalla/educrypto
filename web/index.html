Poin Kunci Penilaian di Depan Dosen Penguji

1. Kepatuhan Aturan Kriptografi

• Caesar & Vigenère: Hanya menggeser alfabet Latin (A–Z, a–z) di dalam ring modulo 26. Pada Vigenère, karakter non-alfabet tidak mengonsumsi indeks kunci sehingga sinkronisasi kata kunci terjaga.
• RC4 Stream Cipher: Mengimplementasikan Key-Scheduling Algorithm (KSA) untuk pengacakan S-Box 256-byte dan PRGA untuk menghasilkan keystream XOR.
• RSA PKCS#1 OAEP: Menggunakan padding OAEP probabilistik (sehingga plaintext yang sama menghasilkan ciphertext berbeda setiap kali dienkripsi) serta mendukung auto-chunking dan validasi kunci privat.

2. Mengapa Ada Super Enkripsi 4-Lapis?

Prinsip Defense in Depth (Shannon's Confusion & Diffusion): lapisan klasik mengaburkan struktur linguistik awal, RC4 menyebarkan bit secara merata (XOR stream), dan RSA-OAEP mengamankan hasil akhirnya dengan kriptografi kunci publik asimetris.

3. Arsitektur Enkripsi File, Gambar & Audio

• Untuk file berukuran besar pada mode RSA/Super, sistem menerapkan standar industri Hybrid Digital Envelope (RSA-OAEP mengenkripsi 256-bit Session Key acak, diikuti stream encryption untuk payload), sehingga file gambar/audio berukuran megabyte selesai dienkripsi dalam hitungan milidetik.
• Setiap file dibungkus dalam kontainer .ecry yang menyimpan hash SHA-256 asli untuk memverifikasi keutuhan file (Integrity Check) saat didekripsi.

4. Metrik Evaluasi Keamanan

• Shannon Entropy: Mengukur keacakan informasi (0 hingga 8 bits/byte).
• Avalanche Effect: Mengukur persentase bit ciphertext yang berubah saat plaintext diubah 1 bit (standar kriptografi modern mendekati ~50%).
• Index of Coincidence (IoC): Membuktikan secara matematis kerentanan sandi klasik terhadap analisis frekuensi.
